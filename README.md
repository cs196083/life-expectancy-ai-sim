# 기대수명 예측 AI 실습실

인공지능 기초 Ⅳ단원 「정형 데이터 인공지능 프로젝트 실제 1 — 기대 수명 예측하기」(191~200쪽) 실습을 브라우저에서 코랩처럼 연습하고 복습하는 시뮬레이터입니다.

## 기능
- **🧪 실습**: 프로젝트 8단계(문제 정의 → 수정 및 성능 개선)의 코드 빈칸을 채우고 ▶ 실행
  - 실제 파이썬과 비슷한 오류 메시지(AttributeError, NameError, FileNotFoundError, 결측치 ValueError 등)와 한국어 도움말
  - 힌트 / 2회 오답 후 정답 보기
  - 실제 WHO 데이터(결측치 제거 후 1,649행)로 그린 히스토그램·히트맵·pairplot·바이올린·회귀선
  - 해 보기: 속성별 상관관계 탐색, test_size 바꿔 보기, 교육 기간으로 기대 수명 예측
- **📝 복습 퀴즈**: 랜덤 10문제, 코드 빈칸 집중, 순서 맞추기, 단계별, 틀린 문제 다시
- **📚 명령어 정리**: 단계별 핵심 명령어 카드(가리기 모드)
- **❗ 오답 노트**: 정답 보기/오답 자동 기록

진행 기록은 학생 각자의 브라우저(localStorage)에만 저장됩니다.

데이터 출처: [Kaggle – Life Expectancy (WHO)](https://www.kaggle.com/datasets/kumarajarshi/life-expectancy-who)
